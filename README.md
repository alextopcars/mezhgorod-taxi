# Междугороднее такси — Белгород

Статический сайт службы междугороднего такси из Белгорода по России.

- Телефон: +7 951 148-88-45
- Telegram: https://t.me/taxi_blg_mezhgorodBot
- Автомобили: комфорт и бизнес-класс

Сайт публикуется на GitHub Pages автоматически при обновлении ветки `main`.

**Форма заказа:** GitHub Pages не поддерживает серверные функции. Форма подготавливает текст заявки и открывает Telegram Share, где пользователь выбирает чат службы и отправляет сообщение вручную.
